
# Plataforma Web Minimarket Mass Sicaya

## Descripción
Desarrollo de una plataforma web para el Minimarket Mass de Sicaya utilizando WordPress y WooCommerce.

## Objetivo
Crear una plataforma web que permita mostrar productos, organizar categorías y facilitar la gestión del minimarket.

## Tecnologías
- WordPress
- WooCommerce
- HTML y CSS
- MySQL

## Estado del proyecto
En desarrollo.

## Control de versiones
Proyecto gestionado con Git y GitHub.
